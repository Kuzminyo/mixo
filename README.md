# Mixo

Микшер громкости для macOS: как в Windows, но в стиле Apple — стеклянная панель в строке меню.

**[⬇️ Скачать последнюю версию](https://github.com/Kuzminyo/mixo/releases/latest)** — файл `Mixo-x.y.zip` в разделе Assets.

- Громкость **каждого приложения отдельно** (браузер, Discord, Spotify, игры…) и кнопка «выключить звук»
- Общая громкость
- Быстрый выбор устройства вывода: динамики, наушники, AirPods, монитор
- Запоминает громкость приложений; «Сбросить» возвращает всё к 100%
- Приложения, у которых громкость 100%, Mixo не трогает — их звук идёт как обычно

Нужна **macOS 26 (Tahoe)** или новее. Работает на Mac с Apple Silicon и Intel.

## Установка готового приложения

1. Скачайте и распакуйте `Mixo-x.y.zip` и перетащите **Mixo.app** в папку «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует.
   Откройте Терминал и выполните:
   ```bash
   xattr -cr /Applications/Mixo.app
   ```
   Или: попробуйте открыть Mixo → «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
3. Запустите Mixo — в строке меню появится значок динамика. Нажмите на него.
4. Когда впервые сдвинете ползунок у приложения, macOS попросит разрешение **«Запись системного звука»** — разрешите.
   Без него громкость отдельных приложений меняться не будет.
5. Автозапуск — переключатель «Запускать при входе» внизу панели.

Если со звуком что-то не так — нажмите «Сбросить» в панели или просто закройте Mixo: звук всех приложений вернётся в норму.

## Сборка из исходников

Нужен Xcode 26 или новее.

```bash
./build.sh install
```

`./build.sh dist` собирает универсальную версию и архивы для отправки в папку `dist`.
